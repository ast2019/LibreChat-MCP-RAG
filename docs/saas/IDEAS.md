# ایده‌ها و کارهای بعدی

هر کار که انجام شد، تیک بزنید (`- [x]`) و نسخه‌ای که در آن آمد را جلویش بنویسید. ایده جدید را زیر بخش مربوط اضافه کنید.

## انجام‌شده

- [x] بسته‌های اعتبار، ضریب قیمت OpenRouter و نوار مصرف (v0.1.0)
- [x] استقرار روی Coolify (v0.1.0)
- [x] ورود با ایمیل و رمز عبور، به‌علاوه OpenID Connect اختیاری (v0.2.0)
- [x] هشدار در ۹۰٪ مصرف و هنگام اتمام اعتبار، با دکمه «خرید بسته» که به `balance.purchaseUrl` لینک می‌شود (v0.2.0)
- [x] Reranker خودکار برای جستجوی وب (Jina/Cohere در صورت وجود کلید) (v0.3.0)
- [x] مدل embedding قوی‌تر برای فارسی: `text-embedding-3-large` (v0.3.0)

## ورود و حساب کاربری

- [ ] **ورود با شماره موبایل (OTP):** سرویس OIDC کوچک (یا Keycloak/Zitadel با افزونه SMS) با کاوه‌نگار یا SMS.ir. از طریق همان متغیرهای `OPENID_*` وصل می‌شود و نیازی به تغییر کد LibreChat ندارد.
- [ ] **Passkey:** در LibreChat از قبل وجود دارد (`ALLOW_PASSKEY_LOGIN`، `PASSKEY_RP_ID`، `PASSKEY_ORIGINS`). کافی است متغیرها به `docker-compose.yml` اضافه و روی دامنه واقعی تست شود.
- [ ] **ورود با نام کاربری:** الان فرم ورود ایمیل می‌خواهد و نام کاربری فقط هنگام ثبت‌نام گرفته می‌شود. اگر ورود با نام کاربری لازم شد، باید استراتژی local تغییر کند.
- [ ] راه‌اندازی SMTP برای تأیید ایمیل و بازیابی رمز عبور

## پرداخت

- [ ] **درگاه پرداخت (زرین‌پال یا IDPay):** سرویس جدا که صفحه خرید را نشان دهد، پرداخت را verify کند و بعد `POST /api/admin/balance/grant` را صدا بزند. شماره تراکنش درگاه باید ذخیره شود تا شارژ تکراری رخ ندهد. بعد از راه‌اندازی، `balance.purchaseUrl` را به صفحه خرید آن اشاره دهید.
- [ ] صفحه ادمین برای دادن بسته، به‌جای API و CLI
- [ ] گزارش ماهانه: مجموع شارژها (`context: pack`) در برابر مجموع مصرف

## ظاهر و زبان

- [ ] **فونت وزیرمتن** به‌عنوان فونت پیش‌فرض `fa`، و پیش‌فرض RTL
- [ ] **تکمیل ترجمه فارسی:** حدود ۶۰٪ کلیدها، از جمله متن‌های هشدار اعتبار v0.2.0، هنوز فقط انگلیسی هستند. این کار بعد از بالا آمدن کامل سیستم انجام می‌شود.
- [ ] صفحه «مصرف من»: نمودار مصرف روزانه، فقط به‌صورت درصد
- [ ] صفحه شروع جستجومحور شبیه Perplexity، با کادر بزرگ و پیشنهاد سوال

## جستجو و فایل‌ها

- [ ] Firecrawl self-hosted برای صفحات سنگین JavaScript
- [ ] کسر هزینه درخواست‌های جستجوی OpenRouter (`web_search`) و embedding فایل‌ها از اعتبار کاربر

## حافظه کاربر

- [ ] **روشن کردن حافظه** (`memory` در `librechat.yaml` و capability `memory`). نمایش «حافظه به‌روز شد» داخل پیام از قبل در LibreChat وجود دارد (`MemoryArtifacts`).
- [ ] **حافظه با همان مدلی که کاربر انتخاب کرده:** LibreChat الان فقط یک مدل ثابت برای حافظه می‌پذیرد، پس این گزینه نیاز به تغییر کد دارد.
- [ ] دستورالعمل حافظه «فعال ولی محتاط»: ترجیحات پایدار کاربر ذخیره شوند، بدون اینکه کاربر بگوید «یادت بماند».
- [ ] بررسی اینکه هزینه مدل حافظه از اعتبار کاربر کسر می‌شود

## حریم خصوصی

- [ ] **ارسال `provider.data_collection: deny` به OpenRouter** از طریق `addParams`: فقط providerهایی استفاده شوند که داده را ذخیره یا برای آموزش استفاده نمی‌کنند. همین را در تنظیمات حساب OpenRouter هم فعال کنید.
- [ ] **حالت «چت محرمانه»** با `provider.zdr: true` (فقط providerهای Zero Data Retention)، همراه با temporary chat که در سرور ما هم ذخیره نمی‌شود
- [ ] صفحه حریم خصوصی و شرایط استفاده (`interface.privacyPolicy` و `interface.termsOfService`)

## جستجوی وب

- [ ] مدل‌های جستجوی بومی دیگر (مثل `perplexity/sonar-reasoning-pro`) به‌عنوان model spec
