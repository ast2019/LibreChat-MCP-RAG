# ایده‌ها و کارهای بعدی

هر کار که انجام شد، تیک بزنید (`- [x]`) و نسخه‌ای که در آن آمد را جلویش بنویسید. ایده جدید را زیر بخش مربوط اضافه کنید.

## انجام‌شده

- [x] بسته‌های اعتبار، ضریب قیمت OpenRouter و نوار مصرف (v0.1.0)
- [x] استقرار روی Coolify (v0.1.0)
- [x] ورود با ایمیل و رمز عبور، به‌علاوه OpenID Connect اختیاری (v0.2.0)
- [x] هشدار در ۹۰٪ مصرف و هنگام اتمام اعتبار، با دکمه «خرید بسته» که به `balance.purchaseUrl` لینک می‌شود (v0.2.0)
- [x] Reranker خودکار برای جستجوی وب (Jina/Cohere در صورت وجود کلید) (v0.3.0)
- [x] مدل embedding قوی‌تر برای فارسی: `text-embedding-3-large` (v0.3.0)
- [x] حافظه بلندمدت کاربر با Gemini Flash روی مسیر ZDR، با نمایش «حافظه به‌روز شد» در پیام و کسر هزینه از اعتبار (v0.4.0)
- [x] چت محرمانه: مدل‌های ZDR با `provider.zdr` و `data_collection: deny` (v0.4.0)
- [x] مدل داخلی روی سرور خودمان (Ollama + `gemma3:4b`) برای چت کاملاً محرمانه (v0.4.0)

## ورود و حساب کاربری

- [ ] **ورود با شماره موبایل (OTP):** سرویس OIDC کوچک (یا Keycloak/Zitadel با افزونه SMS) با کاوه‌نگار یا SMS.ir. از طریق همان متغیرهای `OPENID_*` وصل می‌شود و نیازی به تغییر کد LibreChat ندارد.
- [ ] **Passkey:** در LibreChat از قبل وجود دارد (`ALLOW_PASSKEY_LOGIN`، `PASSKEY_RP_ID`، `PASSKEY_ORIGINS`). کافی است متغیرها به `docker-compose.yml` اضافه و روی دامنه واقعی تست شود.
- [ ] **ورود با نام کاربری:** الان فرم ورود ایمیل می‌خواهد و نام کاربری فقط هنگام ثبت‌نام گرفته می‌شود. اگر ورود با نام کاربری لازم شد، باید استراتژی local تغییر کند.
- [ ] راه‌اندازی SMTP برای تأیید ایمیل و بازیابی رمز عبور

## پرداخت

- [ ] **درگاه پرداخت (زرین‌پال یا IDPay):** سرویس جدا که صفحه خرید را نشان دهد، پرداخت را verify کند و بعد `POST /api/admin/balance/grant` را صدا بزند. شماره تراکنش درگاه باید ذخیره شود تا شارژ تکراری رخ ندهد. بعد از راه‌اندازی، `balance.purchaseUrl` را به صفحه خرید آن اشاره دهید.
- [ ] صفحه ادمین برای دادن بسته، به‌جای API و CLI
- [ ] گزارش ماهانه: مجموع شارژها (`context: pack`) در برابر مجموع مصرف

## ظاهر و زبان

- [ ] **فونت وزیرمتن** به‌عنوان فونت پیش‌فرض `fa`، و پیش‌فرض RTL
- [ ] **تکمیل ترجمه فارسی:** حدود ۶۰٪ کلیدها، از جمله متن‌های هشدار اعتبار v0.2.0، هنوز فقط انگلیسی هستند. این کار بعد از بالا آمدن کامل سیستم انجام می‌شود.
- [ ] صفحه «مصرف من»: نمودار مصرف روزانه، فقط به‌صورت درصد
- [ ] صفحه شروع جستجومحور شبیه Perplexity، با کادر بزرگ و پیشنهاد سوال

## جستجو و فایل‌ها

- [ ] Firecrawl self-hosted برای صفحات سنگین JavaScript
- [ ] کسر هزینه درخواست‌های جستجوی OpenRouter (`web_search`) و embedding فایل‌ها از اعتبار کاربر

## حافظه کاربر

- [ ] **حافظه با همان مدلی که کاربر انتخاب کرده** به‌عنوان گزینه: LibreChat فقط یک مدل ثابت برای حافظه می‌پذیرد، پس نیاز به تغییر کد دارد. فعلاً عمداً از Gemini Flash استفاده می‌شود (ارزان‌تر و پایدارتر).
- [ ] طراحی جذاب‌تر برای «حافظه به‌روز شد»: انیمیشن کوتاه و دکمه «مدیریت حافظه» که مستقیم تنظیمات Personalization را باز کند

## حریم خصوصی

- [ ] فعال کردن «فقط providerهای بدون ذخیره داده» در تنظیمات حساب OpenRouter، به‌عنوان لایه دوم پشتیبان
- [ ] قفل کردن آپلود فایل در چت محرمانه: embedding فایل‌ها الان از مسیر عادی OpenRouter می‌رود (ZDR نیست)
- [ ] مدل داخلی قوی‌تر در صورت داشتن سرور GPU (مثل `qwen3:14b` یا `gemma3:12b`)
- [ ] صفحه حریم خصوصی و شرایط استفاده (`interface.privacyPolicy` و `interface.termsOfService`)

## جستجوی وب (رسیدن به سطح Perplexity و ChatGPT)

- [ ] **API جستجوی پولی:** Serper (نتایج واقعی Google، ارزان) یا Tavily. SearXNG از IP دیتاسنتر گاهی از Google CAPTCHA می‌گیرد.
- [ ] **Reranker:** کد آماده است (v0.3.0)؛ فقط کلید `JINA_API_KEY` لازم است.
- [ ] **Firecrawl** برای خواندن صفحاتی که با JavaScript ساخته شده‌اند (self-hosted یا سرویس ابری)
- [ ] **بهترین ترکیب پیشنهادی: Serper + Jina reranker**
- [ ] reranker محلی سازگار با Jina (مثلاً سرور Infinity) تا کلید تجاری لازم نباشد
- [ ] مدل‌های جستجوی بومی دیگر (مثل `perplexity/sonar-reasoning-pro`) به‌عنوان model spec

## بهتر از ChatGPT و Claude

- [ ] **حالت «پژوهش عمیق»:** چند جستجوی پشت‌سرهم و گزارش ساختاریافته با منبع (مثل Deep Research)، با subagentهای LibreChat
- [ ] **مقایسه هم‌زمان دو مدل** در یک پیام (multiConvo در LibreChat هست، الان خاموش است) و انتخاب پاسخ بهتر
- [ ] **مسیریابی هوشمند مدل:** سوال ساده به مدل ارزان، سوال سخت به مدل قوی، به‌صورت خودکار
- [ ] **پروژه‌ها:** فایل‌ها و دستورالعمل ثابت برای هر پروژه (Chat Projects در LibreChat وجود دارد)
- [ ] **Agentهای آماده فارسی:** مترجم حرفه‌ای، ویراستار، نامه اداری، خلاصه‌ساز جلسه، معلم زبان
- [ ] **ورودی و خروجی صوتی** (STT/TTS فارسی)
- [ ] **تولید و ویرایش تصویر** با مدل‌های تصویری OpenRouter
- [ ] **اجرای کد و تحلیل فایل اکسل/CSV** (Code Interpreter)
- [ ] **پیشنهاد سوال بعدی** زیر هر پاسخ، مثل Perplexity
- [ ] **حالت استدلال (reasoning)** قابل انتخاب برای مدل‌هایی که پشتیبانی می‌کنند
- [ ] اتصال MCP به سرویس‌های کاربر (Google Drive، Gmail، تقویم)
