# پیشنهاد مرورگر Agent (فاز E)

وضعیت: پیشنهاد، منتظر تصمیم مالک. ادامه‌ی همان فاز E در `hivegpt-product-platform-plan-fa.md`.

## وضع فعلی

- پیدا کردن نتیجه: Serper، بعد SerpAPI، Tavily و SearXNG.
- خواندن صفحه: Keenable، که صفحه را ساده و بدون اجرای جاوااسکریپت می‌خواند.
- برای اخبار، ویکی‌پدیا، وبلاگ و مستندات همین کافی است.

## کجا مرورگر لازم است

| نوع سایت | نمونه | دلیل |
|---|---|---|
| فروشگاه و مقایسه‌ی قیمت | دیجی‌کالا، ترب، باسلام | قیمت و موجودی با جاوااسکریپت می‌آید؛ فیلتر و صفحه‌بندی |
| آگهی | دیوار، شیپور | اسکرول بی‌پایان، فیلتر شهر و دسته |
| بلیت و رزرو | علی‌بابا، فلای‌تودی، مستربلیط، جاباما، جاجیگا | نتیجه بعد از پر کردن فرم |
| بورس و بازار | tsetmc، نمودارهای tgju، کدال | داده‌ی زنده و جدول جاوااسکریپتی |
| نقشه | نشان، بلد | محتوای تصویری و تعاملی |
| سایت‌های تک‌صفحه‌ای | سایت‌ها و داشبوردهای React و Vue | بدون جاوااسکریپت تقریباً خالی |
| سایت خود کاربر | بررسی سایت، اسکرین‌شات، نمایش موبایل | چیدمان واقعی لازم است |
| سند عمومی | Google Docs و Sheets عمومی، نمایشگر PDF | نمایشگر جاوااسکریپتی |

## آنچه نمی‌سازیم

- ورود به حساب (بانک، my.gov.ir، ثنا، مالیات، ایمیل).
- شبکه‌های اجتماعی (اینستاگرام، X، لینکدین).
- دور زدن کپچا یا ضدربات.
- برداشت انبوه. سرعت مثل یک کاربر عادی؛ قوانین سایت‌های اصلی پیش از راه‌اندازی بررسی شود.

## نسخه‌ی اول

1. **ابزار «مرور صفحه»** کنار جست‌وجو. مدل اول جست‌وجو و Keenable را به کار می‌برد و فقط وقتی صفحه خالی یا ناقص بود، یا کاربر صریحاً خواست، سراغ مرورگر می‌رود.
2. **کارهای مجاز:** باز کردن نشانی و صبر برای لود، اسکرول، کلیک روی صفحه‌بندی یا «بیشتر»، پر کردن فرم جست‌وجویی که وارد حساب نمی‌کند و چیزی ثبت نمی‌کند. خروجی: متن صفحه و یک اسکرین‌شات در چت. ورود، سفارش، پرداخت و ارسال پیام ندارد.
3. **سرویس جدا:** Playwright و Chromium در کانتینر جدا، با پروفایل موقت برای هر بار، بدون دسترسی به شبکه‌ی داخلی (Ollama، Mongo)، سقف حدود ۶۰ ثانیه و چند صفحه برای هر مرور، و یک یا دو مرورگر همزمان. سرویس خارجی (مثل Browserbase) پیشنهاد نمی‌شود: هزینه‌ی دلاری و خروج داده.
4. **دسترسی و هزینه:** یک دسترسی تازه روی بسته‌ها کنار رسانه و API، کسر هزینه‌ی هر مرور از اعتبار، و سقف روزانه برای هر کاربر.
5. **میان‌بر:** برای سایت‌های پرکاربرد مثل tsetmc یا دیوار، بعداً راه مستقیم ارزان‌تر از مرورگر.

## پرسش‌های باز از مالک

- RAM و CPU سرور. هر Chromium حدود ۳۰۰ تا ۵۰۰ مگابایت RAM می‌خواهد و Ollama هم روی همین سرور است.
- کدام دسته‌ی سایت‌ها اولویت دارد (قیمت، بلیت، آگهی، بورس).
- مرورگر برای همه باشد یا فقط بسته‌های خاص.
